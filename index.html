Android Release Seal · v1.0.0

Most of what you can do before commercial hardening

DroidSeal covers most of what you can do before commercial hardening — environment diagnostics, source & APK audit, R8 obfuscation, zipalign, apksigner signing, and final verification. One command, end to end.

14-Step Pipeline

A 14-step pipeline, end to end

From APK to signed artifact, entirely on your machine. Every step produces an independent, auditable, rollback-safe artifact with sensible defaults.

01

Environment check

Locates JDK / Android SDK tools and flags what the selected flow is missing.

02

Prepare workspace

Validates input and copies the existing APK; never modifies in place.

03

Keystore

Validates the existing alias up front, or creates one with keytool.

04

Source security audit

Checks R8 / resources / Manifest / plaintext signing passwords and source heuristics.

05

Build release APK

Runs the project's own Gradle Wrapper and copies the artifact.

06

APK security audit

Parses ZIP / DEX / ELF / AXML / ARSC; aapt only as a fallback.

07

Local hardening

Verifies R8, standard DEX, anti-debug and integrity coverage.

08

Release normalization

Forces debuggable=false, verifies after modification, otherwise aborts and rolls back.

09

Web JS handling

Optional Terser pass over assets/public and assets/www scripts.

10

Resource name obfuscation

Optionally parses resources.arsc, preserving entries hit by getIdentifier.

11

ZIP alignment

zipalign -p -f 4; auto-skips when a valid signature is preserved.

12

APK signing

apksigner outputs a new signed APK.

13

Final verification

Verifies alignment, signing scheme, certificate, and computes SHA-256.

14

Report

JSON / Markdown, SBOM, release gate and coverage matrix.

Three Entry Points

Three entry points, one engine

One engine, three paces — learn step by step, run it in one click, or diagnose the environment first.

[1] GUIDED · /guided

Guided

Shows the purpose and impact before each step; run or skip it, and failures roll back to the APK from before the step.

[2] ONE-CLICK · /oneclick

One-click

Runs all 14 steps after you fill in the details; ordinary failures roll back and continue, while missing tools pause for download or repair.

[3] DOCTOR · /doctor

Doctor

Locates JDK / Android SDK tools, lists what is missing with download hints; checks only, never modifies the package.

Capabilities

Capability grid

Not a black box — a local-first, auditable, verifiable pre-release pipeline.

Local-first

No model service calls; never uploads your APK, file paths, or signing credentials.

Verifiable results

Produces signature verification, SHA-256, and JSON / Markdown reports.

Rollback-safe

Every step keeps an independent artifact; failures explain why and restore the last valid APK.

Deep static audit

Permissions / targetSdk / signing / deep links / hardcoded secrets / TLS heuristics.

Secret redaction

Plaintext passwords keep only path and line; values never reach reports or commands.

Evidence-first

Reports distinguish confirmed / high / medium / low confidence and emit a CycloneDX SBOM.

Security & Privacy

Security & privacy, right by default

Local-first execution

APKs and signing credentials are handled only on your machine; no model service, no uploads.

Clear boundaries

By default no unpacking, hooks, anti-debug, or runtime tampering code is injected; such attacks are treated only as a threat model.

Secrets never touch disk

Plaintext passwords live only in memory, never in reports, command arguments, config files, or chat history.

Evidence-first

Reports clearly separate "verified" from "advisory" controls and never claim a server-side closed loop.

Trouble installing?

SmartScreen blocks the downloaded exe

The droidseal.exe from GitHub Releases is not code-signed, so Windows may warn "Windows protected your PC". Fix: right-click the exe → Properties → check "Unblock" → OK; or click "More info → Run anyway"; you can also run it directly in PowerShell.

The TUI needs a terminal

DroidSeal is a terminal program: double-clicking droidseal.exe shows "interactive terminal required" and exits. Open PowerShell or cmd, cd into the extracted folder and run .\droidseal.exe, or double-click the bundled droidseal-gui.cmd launcher.
